# EduSmart
Enterprise learning management platform for students, teachers, parents and administrators.

## Major Modules
- Student Portal
- Teacher Portal
- Course Management
- Video Learning
- Live Classes
- Assignment System
- Quiz Module
- Automatic Evaluation
- Attendance Management
- Student Analytics
- Teacher Analytics
- Learning Progress Tracking
- Note Sharing
- Discussion Forum
- Certificates
- Notification System
- Admin Dashboard
- File Manager
- Academic Reports
- Parent Monitoring Panel
- Gradebook
- Course Enrollment
- Question Bank
- Learning Calendar
- Content Moderation
- Teacher Scheduling
- Fee Management
- Helpdesk
- Audit Logs
- API Management

## Stack
React + Next.js + Tailwind-ready UI architecture, Node.js + Express, PostgreSQL, JWT + OAuth, Docker, Git, Vercel/Render.

## Local Setup
```bash
cd backend
npm install
npm run dev
```
In another terminal:
```bash
cd frontend
npm install
npm run dev
```

See `docs/API.md`, `docs/ARCHITECTURE.md`, `docs/DEPLOYMENT.md`, and `docs/PAGES.md`.
